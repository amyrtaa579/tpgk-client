

# 🤖 Бот для мессенджера MAX (DocsClient)

Бот для мессенджера MAX, предоставляющий информацию о поступлении, специальностях, фактах и проводящий тестирование. Взаимодействует с внешним API для получения актуальных данных.

## 🛠 Стек технологий

- **Node.js** 20.x
- **TypeScript**
- **MAX Messenger API** (SDK мессенджера MAX)
- **PM2** (рекомендуется для фоновой работы на Windows)

## 📁 Структура проекта

```text
.
├── src/
│   ├── config/         # Конфигурация и настройки (settings.ts)
│   ├── handlers/       # Обработчики команд (start, about, admission, etc.)
│   ├── keyboards/      # Клавиатуры для бота (inline.ts)
│   ├── models/         # Модели данных и типы TypeScript
│   ├── services/       # Внешние сервисы (apiClient.ts для запросов к API)
│   ├── utils/          # Вспомогательные функции и хелперы
│   └── main.ts         # Точка входа в приложение
├── .env                # Переменные окружения (не коммитить!)
├── package.json        # Зависимости и скрипты
└── tsconfig.json       # Конфигурация TypeScript
```

## ⚙️ Переменные окружения

Создайте файл `.env` в корневой папке проекта:

```env
# Токен бота в мессенджере MAX
BOT_TOKEN=your_token

# Настройки внешнего API
API_URL=https://(поддомен|домен|ip:порт)_вашего_api/api/v1
API_KEY=
API_TIMEOUT=30000

# Логирование (debug, info, warn, error)
LOG_LEVEL=info

# ID администраторов бота (через запятую, без пробелов)
ADMIN_IDS=123456789,987654321
```
> ⚠️ **Важно:** Файл `.env` содержит секретные данные и уже добавлен в `.gitignore`. Не загружайте его в репозиторий.

## 🚀 Установка и запуск на Windows

### 1. Установка Node.js
1. Скачайте и установите **Node.js 20.x (LTS)** с официального сайта: https://nodejs.org/
2. Откройте PowerShell или Командную строку (CMD) и проверьте установку:
   ```powershell
   node -v   # Должно быть v20.x.x
   npm -v
   ```

### 2. Установка зависимостей
В терминале перейдите в папку с проектом (`cd C:\путь\к\docsclient`) и выполните:
```powershell
npm ci
```

### 3. Сборка проекта
Скомпилируйте TypeScript в JavaScript:
```powershell
npm run build
```
*После этого появится папка `dist` с готовым кодом.*

### 4. Быстрый запуск (для тестов)
Создайте в корне проекта файл `start.bat` со следующим содержимым:
```bat
@echo off
set NODE_ENV=production
set NODE_TLS_REJECT_UNAUTHORIZED=0
node dist/main.js
pause
```
Просто запустите `start.bat` двойным кликом.

## 🖥 Постоянная работа в фоне (Production на Windows)

Чтобы бот работал постоянно, не закрывался при выходе из системы и перезапускался при сбоях, используйте **PM2**.

### Шаг 1: Установите PM2 глобально
```powershell
npm install -g pm2
```

### Шаг 2: Запустите бота через PM2
Выполните в папке проекта:
```powershell
pm2 start dist/main.js --name "max-docs-bot" --env production
```
*(PM2 автоматически подхватит переменные из файла `.env`, если он лежит в той же папке).*

### Шаг 3: Настройте автозапуск при включении Windows
```powershell
pm2 startup
pm2 save
```
*Следуйте инструкциям в терминале (возможно, потребуется запустить PowerShell от имени Администратора для выполнения команды `pm2 startup`).*

### Полезные команды PM2:
| Команда | Описание |
|---------|----------|
| `pm2 list` | Показать статус всех запущенных процессов |
| `pm2 logs max-docs-bot` | Посмотреть логи бота в реальном времени |
| `pm2 restart max-docs-bot` | Перезапустить бота (после обновления кода и `npm run build`) |
| `pm2 stop max-docs-bot` | Остановить бота |
| `pm2 delete max-docs-bot` | Полностью удалить процесс из PM2 |

## 📝 Обработанные команды бота

- `/start` — Приветственное сообщение и основное меню
- `/about` — Информация об организации
- `/admission` — Информация о поступлении
- `/specialties` — Список специальностей
- `/facts` — Интересные факты
- `/faq` — Часто задаваемые вопросы
- `/test` — Запуск тестирования/викторины
