
# 🤖 ТПГК Max Bot

Бот для мессенджера **MAX**, предоставляющий абитуриентам и студентам Томского промышленно-гуманитарного колледжа (ТПГК) актуальную информацию о поступлении, специальностях, проведении профориентационного тестирования и ответами на часто задаваемые вопросы.

Взаимодействует с внешним REST API ([tpgk-server](https://github.com/amyrtaa579/tpgk-server)) для получения данных.

## ✨ Возможности

### 🏫 О колледже
- Подробная информация о ТПГК
- История и достижения
- Фотографии колледжа

### 🎓 Специальности
- Каталог всех специальностей с **пагинацией**
- Детальная информация по каждой специальности:
  - Описание и краткое описание
  - Варианты обучения (бюджет/платное)
  - Количество мест
  - Срок обучения
  - Необходимые экзамены
- **Интересные факты** по каждой специальности с изображениями

### 📋 Приёмная кампания
- Способы подачи документов (онлайн, офлайн, через Госуслуги)
- Важные даты приёмной кампании
- Специальности с информацией о местах
- Вопросы для поступающих (FAQ приёмной кампании) с пагинацией

### ❓ Часто задаваемые вопросы (FAQ)
- Категоризация вопросов
- **Пагинация** (по 9 вопросов на странице)
- Прикреплённые документы к ответам
- Изображения в ответах

### 🧪 Профориентационный тест
- Интерактивный тест для подбора специальности
- Множественный выбор ответов
- Прогресс-бар прохождения
- Результаты с топ-3 подходящими специальностями
- Изображения к вопросам

### 📢 Дополнительные функции
- Автоматическое сохранение ID чатов для рассылки
- Скрипт массовой рассылки (`broadcast.ts`)
- Получение списка пользователей (`get_users.ts`)

## 🛠 Стек технологий

- **Node.js** 18+ (рекомендуется 20.x LTS)
- **TypeScript** 5.4+
- **@maxhub/max-bot-api** — официальный SDK мессенджера MAX
- **REST API** — взаимодействие с бэкендом
- **PM2** (опционально) — для фоновой работы на сервере

## ⚙️ Переменные окружения

Создайте файл `.env` в корневой папке проекта:

```env
# Токен бота в мессенджере MAX
BOT_TOKEN=your_bot_token_here

# URL API бэкенда (tpgk-server)
API_URL=https://api.anmicius.ru/api/v1

# API ключ для авторизации (если требуется)
API_KEY=your_api_key_here

# Таймаут запросов к API (мс)
API_TIMEOUT=30000

# Уровень логирования: debug, info, warn, error
LOG_LEVEL=info

# ID администраторов бота (через запятую)
ADMIN_IDS=123456789,987654321
```

> ⚠️ **Важно:** Файл `.env` содержит секретные данные и уже добавлен в `.gitignore`. **Никогда не загружайте его в репозиторий!**

## 🚀 Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/amyrtaa579/tpgk-client.git
cd tpgk-client
```

### 2. Установка зависимостей

```bash
npm install
# или
npm ci  # для чистой установки из package-lock.json
```

### 3. Настройка переменных окружения

```bash
cp .env.example .env  # если есть .env.example
# или создайте .env вручную (см. раздел "Переменные окружения")
nano .env
```

### 4. Сборка проекта

```bash
npm run build
```

*После этого появится папка `dist` с скомпилированным JavaScript кодом.*

### 5. Запуск

#### Режим разработки (с автоматической компиляцией)
```bash
npm run dev
```

#### Продакшен
```bash
npm start
```

#### Через bash-скрипт (Linux)
```bash
chmod +x start-bot.sh
./start-bot.sh
```


## 🌐 API эндпоинты

Бот взаимодействует со следующими эндпоинтами бэкенда:

| Метод | Эндпоинт | Описание |
|-------|----------|----------|
| GET | `/api/v1/about` | Информация о колледже |
| GET | `/api/v1/specialties` | Список специальностей (с пагинацией) |
| GET | `/api/v1/specialties/{code}` | Детали специальности |
| GET | `/api/v1/specialties/{code}/facts` | Интересные факты |
| GET | `/api/v1/facts/{id}` | Детали факта |
| GET | `/api/v1/admission` | Приёмная кампания |
| GET | `/api/v1/faq` | FAQ (с фильтрацией по категории) |
| GET | `/api/v1/documents` | Список документов |
| GET | `/api/v1/test/questions` | Вопросы теста |

## 📝 Команды бота

| Команда | Описание |
|---------|----------|
| `/start` | Запустить бота, показать главное меню |

**Кнопки главного меню:**
- 🏫 О колледже
- 🎓 Специальности
